# 사운드 설계

## 소리 네 층

| 층 | 만드는 곳 |
|---|---|
| 대사 | 시댄스 (영상 생성 시 같이) |
| 박만수 속마음 | 일레븐랩스 eleven_v4, `docs/characters.md`의 목소리 |
| 효과음 | 시댄스 기본음 + 매그니픽 효과음(`audio_sfx_generate`)으로 보강 |
| 배경음악 | 매그니픽 음악 생성, 구글 Lyria 3 Pro (곡당 160크레딧, 30~180초) |

## 효과음 원칙

- 예능식 효과음("띠용", 정적, 귀뚜라미)은 **개그 포인트에만, 한 클립에 한두 개.**
- 1화 후보 자리: "누구세요" 직후 정적 / 투구 거꾸로 쓰는 순간 / "재고 얘긴가" 뒤 / "쥐가 소만 해졌겠소" 뒤.

## 믹싱 기준

- 대사가 나올 때 배경음악을 자동으로 낮춘다(덕킹). 대사가 묻히면 노인 시청자가 이탈한다.
- 최종 음량은 유튜브 기준 -14 LUFS.
- 효과음과 믹싱은 한 화 영상을 다 뽑은 뒤 마지막에 한꺼번에 한다. 클립을 다시 뽑으면 타이밍이 바뀌기 때문이다.
