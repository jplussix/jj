```

git checkout claude/youthful-maxwell-d8e8xd
```

그 폴더에서 Claude Desktop(또는 터미널 `claude`)을 열고 첫 메시지로: "docs/HANDOFF.md 읽고 이어서 하자".

## 2. 데스크탑에 따로 준비할 것 (클라우드에만 있던 것)

| 항목 | 클라우드에서 쓰던 방식 | 데스크탑에서 |
|---|---|---|
| ffmpeg, python3, numpy | 설치돼 있음 | 설치 필요 |
| Whisper (무료 받아쓰기, `tools/transcribe.py`) | `pip install openai-whisper` + torch, 모델 medium | 같은 명령으로 설치. 첫 실행 때 모델(1.5GB) 자동 다운로드 |
| 일레븐랩스 API (복제 목소리 TTS) | 환경 비밀값으로 자동 주입(`xi-api-key: proxy-injected`) | 환경변수 `ELEVENLABS_API_KEY`에 `sk_…` 키를 넣고, 요청 헤더를 `xi-api-key: $ELEVENLABS_API_KEY`로 |
| 힉스필드·매그니픽·일레븐랩스 커넥터 | claude.ai 커넥터 | 데스크탑 앱에서도 같은 계정 커넥터가 보이는지 확인 |
| 아르곤(제미나이) | `~/.local/bin/agy` (안티그래비티 CLI, 구글 AI Pro 로그인) | 안티그래비티 CLI 설치 후 로그인. `tools/episode_writer.py`의 `AGY` 경로 확인 |
| GPT 이미지 | `codex` CLI (ChatGPT 로그인, `codex login --device-auth`) | codex CLI 설치 후 로그인 |
| 한글 손글씨 폰트 | `fonts-nanum-extra` (나눔손글씨 펜) | 나눔손글씨 펜/나눔고딕 설치 (러프컷 자막용) |
| 대화 기록 `handoff/chat_log.md` | 로컬 전용(커밋 금지) | 옮겨지지 않음. 이 인계 메모가 대신한다 |

## 3. 지금 상태 (1화)

- 대본: `scripts/ep01.md` (씬 1~8, 7-2~7-4 추가로 약 9분).
- 클립 프롬프트: `storyboard/ep01/clips.md`. 테이크 기록: `storyboard/ep01/clip0*_takes.md`.
- 러프컷: `renders/ep01/ep01_roughcut_v3.mp4` (8분 19초), 만드는 스크립트 `tools/rough_cut_ep01.py`.
  - 클립 순서, 자막(06~08은 Whisper 시간), 효과음, 배경음악(장면 시작·전환·핵심 순간만, 낮게), 속마음 VO, 화면 전환이 전부 이 스크립트에 있다.
  - 소리 싱크: 시댄스 원본 소리를 60ms 앞당김(`AV_SHIFT`, 사용자 A/B 확인).
  - 세그먼트는 24fps 프레임 단위로 길이를 맞춰야 싱크가 안 밀린다(스크립트에 반영).
- 속마음: 영상 속 박만수 목소리를 복제한 일레븐랩스 목소리 `박만수 (영상 클론)` voice_id `2QR7415RxATcyYH6g8Rd`, 모델 eleven_v4, 감정 태그 + speed 1.12. 파일 `audio/ep01/inner/v2/`. v4가 첫마디를 반복하는 일이 잦아 Whisper로 확인 후 잘라 냄(`*_fx.mp3`).
- 크레딧: 힉스필드 시댄스 2.5는 초당 3크레딧. 생성 전에 무엇을 몇 크레딧에 돌릴지 매번 확인받는다(CLAUDE.md).
